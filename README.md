# 明星衣橱 · Star Closet

一个以电影式镜头呈现衣橱与服饰的互动体验项目。

我们希望用户进入一个有高级感、经过艺术化处理的 3D 衣橱，跟随设计好的镜头浏览服饰，点击查看细节，并通过外链前往零售商页面。

**当前阶段：需求整理与技术可行性讨论，尚未开始开发。用户明确要求：不要开始写代码。**

## 当前状态

- **已确认**：采用电影式、经过编排的镜头体验；技术可行性优先；场景应保护隐私。
- **建议**：一个房间、三个镜头状态、六至八件服饰，至少一件使用真实 GLB 模型。
- **待验证**：不同素材如何支持放大、翻面和 360° 查看，以及目标设备上的效果。
- **待决策**：技术栈、首版范围、素材方案和最终品牌名称。
- 明星合作属于产品设想，目前没有已确认的合作或授权。

## 状态含义

- **已确认**：用户明确选择或限制，有可追溯依据。
- **建议**：供讨论，尚未获批。
- **待验证**：缺少实验、授权或其他证据。
- **已完成**：有可检查的交付物或操作结果。

不要把建议自动当作开发任务。当前的首版候选范围尚未批准。图片、图片组和真实 3D 模型必须如实区分；没有背面素材时不能声称支持真实翻面或完整 360° 查看。
