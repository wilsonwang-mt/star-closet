# T1 演示视频（Remotion）报告

工作站：Mac Studio「Star Closet 项目工作站」。分支 `feat/studio-demo-video`，基于 `origin/feat/core-adapt-20261015` 的 `353b9c1`。2026-10-16 19:15–19:33（SGT）。只在 `demo-video/` 下工作。

## 工程

- Remotion **4.0.524**（TypeScript）。两个合成：`DemoLandscape` 1920×1080、`DemoPortrait` 1080×1920，30fps，2700 帧 = 90.00 秒。
- 入口 `src/index.ts`；`src/Root.tsx`（合成与默认参数）、`src/Demo.tsx`（分镜与转场）、`src/scenes.tsx`（6 段画面）、`src/components.tsx`（场景层、胶片颗粒、浮起文字、玻璃卡、录屏占位、LIVE 标）、`src/theme.ts`（视觉规范 v5 的颜色与字体）。
- 视觉：深石墨底、暖白文字、香槟金；刊头 Bodoni、中文标题宋体；场景缓慢推镜，片头从虚焦暗场推到清晰；胶片颗粒（深色 .14）；弹簧浮起；段间 0.6 秒弹簧淡入淡出；N° 与价格用金箔渐变流光。
- 命令（在 `demo-video/` 下）：

```bash
npm install
npm run preview   # 半分辨率预览，输出 out/preview-*.mp4
npm run render    # 正式 1920×1080 与 1080×1920
npm run studio    # 本地预览编辑器
```

`npm run assets`（上面三条都会先执行）把素材复制到 `public/`：`docs/design/visual-v04/video`、`keyframes` → `public/brand/`；`app/public/catalog/outfits` → `public/brand/outfits/`；`app/public/demo`（T2，合并后才有）→ `public/demo/`。这些副本已在 `.gitignore` 中忽略，不在仓库里重复保存。

## 遇到的问题

1. **Remotion 4.0.536 渲染卡死**：最初装的是 npm 最新版 4.0.536（2026-10-16 当天发布），连最小的测试合成都卡在“Waiting for root component to load”（delayRender 超时）。排除了字体、命令沙箱和代理后，换成 2026-09-12 发布的 4.0.524 即正常。版本已固定为 4.0.524。
2. **字体**：Bodoni Moda（拉丁）渲染时经 `@remotion/google-fonts` 从 Google Fonts 下载，**需要联网**。中文没有走 Google Fonts（思源宋体 / 思源黑体要 100–200 个分片，渲染慢），改用本机字体：优先已安装的 Noto Serif SC / Noto Sans SC，没有时用 macOS 自带的宋体（Songti SC）与苹方（PingFang SC）。工作站上实际用的是 macOS 自带字体，与网站的思源字体略有差别。正式渲染前如果要严格一致，可以在本机安装思源宋体与思源黑体。
3. 竖屏“一句话改编”段底部的要求浮层会压住录屏框下沿一点，放入真实录屏后再按画面微调位置。
4. 没有配音和配乐。
