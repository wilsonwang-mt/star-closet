# T5 真机测试与质检（持续任务）

目的：工作站在 Mac Studio 上用真实 key 跑完整产品，替指挥台做端到端测试、回归和问题记录。工作站只测试和记录，**不修改 `app/` 代码**，修复由指挥台负责。

## 准备

1. `git fetch origin`，在一个单独的目录里检出 `origin/main`（可以用 `git worktree add ../star-closet-qa origin/main`），不要在 T1 到 T3 的分支里测。
2. 把 Mac Studio 的 `app/.env.local` 复制到这个测试目录的 `app/` 下（不要提交）。里面应该有 `FAL_KEY`、`AVATAR3D_PROVIDER=metaperson`、`AVATARSDK_CLIENT_ID`、`AVATARSDK_CLIENT_SECRET`、`ANTHROPIC_API_KEY`、数据库和 `BETTER_AUTH_*` 变量。缺哪个就写进报告。
3. `cd app && npm install && npm run build && npm start -- -p 3100`，端口用 3100，避免和其他服务冲突。构建卡在 Google 字体时，按 `app/README.md` 写的绕法处理。
4. 测试账号自己注册，邮箱用 `qa+<任意>@starcloset.test`，密码随机生成，记进本机 `app/.env.local`（不要提交）。
5. 测试用的人像只能用 AI 生成的虚构人物。可以用 T2 生成的 f01、m01，T2 还没出图就先用 fal 生成一张。不能用任何真人照片。

## 测试清单（每项记录：结果、耗时、截图路径、问题）

**A. 首页与浏览**
- 首页浅弧轮播，点“走进衣橱”进入衣橱页，转场是否流畅。
- 10 间衣橱和 60 套搭配都能打开。
- 悬浮玻璃胶囊导航自动隐藏。
- 深色和浅色两种模式都要看。
- 每项分别在 1440 宽、768 宽、375 宽下检查。

**B. 一句话改编**
- 输入“预算 800，户外婚礼，换平底鞋”，记录结果是否合理、总价、耗时。
- 再测 3 条不同的需求。

**C. 3D 形象（MetaPerson）**
- 进入 `/profile/avatar`，勾选同意，记录创建器首次加载用了多久。
- 上传虚构人物的自拍，记录生成耗时，然后点“保存为我的 3D 形象”。
- 记录导入是否成功。如果提示“导出地址的主机 xxx 不在白名单中”，**记下完整主机名**，这是最重要的信息。
- 保存后检查金色展示框里 360° 旋转、重新生成、删除这个形象、一键删除。
- 同一个账号再测一次手机宽度（窗口窄于 768）下的手机版创建器。

**D. 2D 试穿（fal FASHN）**
- 在试衣间或搭配页点“穿在我身上”，上传虚构人物的全身正面照，勾选同意后试穿。
- 记录耗时、已穿上的品类，以及结果里的衣服和商品图是否一致。
- 用另一个账号访问第一个账号的试穿结果链接，应返回 404。

**E. 稳定性**
- 断网或弱网时（可用 Chrome DevTools 节流），各页面的加载和出错表现。
- 浏览器控制台有没有报错。
- 服务端日志里有没有报错。

**F. 新功能合并后复测**
指挥台会陆续合并下面三项到 main。每次 main 有新提交，就拉取、重新构建，把受影响的部分再测一遍：
- 试衣间逐件试穿；
- 3D 形象多照片上传与体型分析；
- T3 商品详情页。
