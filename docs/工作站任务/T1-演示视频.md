# T1 演示视频 Remotion 框架

目的：先把比赛演示视频的框架搭好；网站功能冻结后（T4）再填入真实录屏。

## 步骤

1. **分支**：`git fetch` 后，基于 `origin/feat/core-adapt-20261015` 新建 `feat/studio-demo-video`。只在新目录 `demo-video/` 下工作，不改 `app/`、`docs/` 等其他目录。
2. **工程**：在 `demo-video/` 初始化 Remotion 工程（TypeScript），可以用 Remotion 技能。成片 90 秒、1920×1080、30fps，另出一版 1080×1920 竖屏。
3. **分镜**（时长供参考，可微调）：
   - 0–8s 片头：`docs/design/visual-v04/video/night-wide-web.mp4` 夜景横移，叠 Bodoni 刊头“STAR CLOSET”和一句“让每一种喜欢的风格，都能穿到自己身上”。
   - 8–20s 痛点：收藏了一百套穿搭，还是不知道自己该怎么穿。
   - 20–40s 走进衣橱：首页浅弧轮播 → 走进衣橱（录屏占位）。
   - 40–60s 一句话改编：输入“预算 800，户外婚礼，换平底鞋”→ AI 改编结果 ¥797（录屏占位）。
   - 60–78s 穿在我身上：自拍生成 3D 形象并 360° 旋转；商品详情页的场景上身图与 Live 效果（录屏占位，可先用 T2 产出的场景图和 Live 视频）。
   - 78–90s 收尾：愿景加产品名，背景用 `docs/design/visual-v04/keyframes/night-portrait.jpg` 或 day-closet 视频。
4. **视觉**：遵循 `docs/design/visual-v04/视觉规范.md`。香槟金、深石墨，Bodoni Moda 加思源宋体，缓慢推镜、胶片颗粒、弹簧转场，克制高级。
5. **录屏占位**：统一命名，例如 `demo-video/public/recordings/02-closet.mp4`；文件不存在时显示占位卡，之后直接替换文件即可。
6. **预览**：先渲染一版带占位的低分辨率预览确认节奏。渲染产物放 `demo-video/out/`，加入 `.gitignore`，不提交大文件。
7. **交付**：提交并推送 `feat/studio-demo-video`（不推 main）。报告写在 `demo-video/报告.md`：commit、预览视频的本机路径、各分镜实际时长、需要哪些录屏素材；字体如果要联网下载也写明。
