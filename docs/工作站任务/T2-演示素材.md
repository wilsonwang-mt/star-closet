# T2 演示素材生成（fal）

目的：为商品详情页“上身效果”和 Live 动态效果准备演示素材，让演示不受现场网络影响。产品里的实时生成功能照常保留。

预算：用户已批准 fal 花费上限 **20 美元**。累计到 18 美元就停。

前提：`app/.env.local` 里要有 `FAL_KEY`（用户已在 Mac Studio 填好）。没有就停下，写进报告。

## 步骤

1. **分支**：`git fetch` 后，基于 `origin/feat/core-adapt-20261015` 新建 `feat/studio-demo-assets`。
   - 只新增 `app/public/demo/` 和根目录 `demo-assets/`（放脚本和报告），不改其他文件。
   - 生成脚本写成 node 脚本，放在 `demo-assets/scripts/`；key 从 `app/.env.local` 读，不写进脚本，也不打印到日志。
   - fal 调用方式：`POST https://fal.run/<model>`，请求头 `Authorization: Key $FAL_KEY`。图片可以用 data URI（base64）传入。
2. **演示模特**：生成 2 位虚构的 AI 模特。
   - f01 女性、m01 男性，二十多岁，东亚面孔，长相自然亲切，不能像任何真实的人或明星。
   - 每人三张：全身正面照（白 T、素色裤子、浅米色影棚背景、头到脚完整）、半身照、自然光自拍。三张必须是同一张脸。
   - 全身照用 `fal-ai/nano-banana-pro`；半身照和自拍用 `fal-ai/nano-banana-pro/edit`，以全身照为参考。
   - 输出：`app/public/demo/models/f01-full.jpg`、`f01-half.jpg`、`f01-selfie.jpg`，m01 同理。
3. **单品挑选**：从 `app/data/catalog.json` 挑 8 件主打单品，5 件女装，3 件男装或中性。
   - 优先上衣、连衣裙、外套等上身后看得清的品类，平铺图要清楚；尽量覆盖首页靠前的几间衣橱。
   - 商品图在 `app/public/catalog/items/{itemId}.webp`。在报告里记录 itemId 和挑选理由。
4. **场景上身图**：每件 2 个场景，共 16 张。
   - 用 `fal-ai/nano-banana-pro/edit`，输入：模特全身照、商品图、场景描述。
   - 场景按单品风格从这些里选：周五的咖啡馆、城市街头黄昏、户外草坪婚礼、美术馆、海边度假、周末市集。
   - 画面要求：电影感、香槟金暖光、3:4 竖构图、模特自然走动或停留的瞬间；**商品的颜色、款式、材质必须和商品图一致**。
   - 逐张检查，不像商品的重做，每张最多重做 1 次。
   - 输出：`app/public/demo/scenes/{itemId}-{scene}.jpg`，长边 1600，每张 400KB 以内。
5. **Live 视频**：每张场景图生成一段 3 到 4 秒的 image-to-video。
   - 动作细微：发丝、衣摆、光影流动，加一点推镜；首尾尽量能无缝循环；不要音频。
   - 开跑前先查好 fal 上所选模型的单价，选画质好、价格合适的一个，写进报告。
   - 按优先级生成：先给每件单品的第 1 个场景做，钱够再做第 2 个。
   - 输出：`app/public/demo/live/{itemId}-{scene}.mp4`（H.264，约 720×960，每段 2MB 以内），场景图就是封面。压缩可以用 macOS 自带的 `avconvert`。
6. **记账**：每次调用记到 `demo-assets/费用明细.csv`，字段为时间、模型、用途、单价、累计。
7. **清单文件** `app/public/demo/manifest.json`：

   ```json
   {
     "models": {
       "f01": { "full": "/demo/models/f01-full.jpg", "half": "/demo/models/f01-half.jpg", "selfie": "/demo/models/f01-selfie.jpg" },
       "m01": { "full": "…", "half": "…", "selfie": "…" }
     },
     "items": {
       "I0xx": {
         "model": "f01",
         "scenes": [
           { "id": "cafe", "title": "周五的咖啡馆", "image": "/demo/scenes/I0xx-cafe.jpg", "live": "/demo/live/I0xx-cafe.mp4" }
         ]
       }
     }
   }
   ```

   没有 Live 的场景，`live` 填 `null`。
8. **交付**：提交并推送 `feat/studio-demo-assets`（不推 main）。报告写在 `demo-assets/报告.md`：选了哪些单品、视频用的模型和单价、实际总花费、哪些图重做过、遗留问题。建议先推一版模特图和前几张场景图，便于指挥台早看效果。

## 验收

- 16 张场景图里，商品和商品图一眼能对上；同一位模特在各张图里是同一张脸。
- manifest 里的每个路径都存在；视频能在浏览器里播放，每段 2MB 以内。
- 总花费不超过 20 美元，有明细。
