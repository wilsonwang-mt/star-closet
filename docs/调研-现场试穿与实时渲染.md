# 调研：现场试穿与实时渲染（D60、D61）

2026-10-16 约 21:17–21:22（UTC+8）。Mac Studio「Star Closet 项目工作站」按发起用户要求安排的调研，分三路并行（三个调研助手，只做网络检索与阅读，没有注册账号、申请试用或运行第三方代码），工作站汇总并用 fal 价格接口复核了 fal 上三个模型的单价。

用户要求（原话）：“你去安排一次调研，找到成熟的做法，我现在知道的是中国的得物 APP，可以打开摄像头，直接试穿鞋子的上身效果。你研究一下他们是怎么做的？另一方面中国的淘宝。还有就是在git上看一下有没有现成的可以使用的服务，最后，再去看一下有没有这样的 AI 平台提供 API 接入。”

标注：价格、指标多为厂商宣传或第三方数据，已注明来源；“未查到”表示检索中没找到，不代表不存在。许可证判断按字面，不是法律意见。

## 0. 结论先看

1. **行业里，衣服没有成熟的“实时 AR 试穿”。** 得物与淘宝的实时 AR 只用于鞋、手表、美妆等刚体配件；衣服一律是“上传照片 → AI 生成静态试穿图”，淘宝千问试穿甚至还原不了真实体型。
2. **鞋能实时，是因为鞋不变形**：估计脚的姿态再套固定 3D 模型即可；门槛是 3D 模型库（得物有数千到数万个模型）。我们没有鞋的 3D 模型，比赛前不做试鞋。
3. **目前唯一现成的“打开摄像头就实时看到衣服穿上”方案是 Decart Lucy VTON Realtime**，fal 上有托管（与我们现有 fal 账号同一平台），**0.02 美元/秒（fal 价格接口复核）**，浏览器经 WebRTC 接入，有官方 Next.js 示例。闭源、付费，延迟和帧率没有公开数字，不支持鞋。
4. **2D 试穿 API 很多**：Kling Kolors 0.07 美元/张、约 10–13 秒，比现用 FASHN（0.075 美元、约 20 秒）快；阿里云百炼 OutfitAnyone 0.2–0.5 元/张、大陆可用；Google Vertex 有“不用于训练”承诺。
5. **“真实又实时”的走动**：MetaPerson 形象骨骼兼容 Mixamo，可以下载走路动画在 three.js 里播放（未实测）；但**没有任何 API 能把商品图变成可以穿在形象身上的 3D 服装**，“本人穿着这件商品实时走动”赛前做不到。

**2D → 3D 与形象动画**

- [microsoft/TRELLIS](https://github.com/microsoft/TRELLIS)（MIT）、[Hunyuan3D-2](https://github.com/Tencent-Hunyuan/Hunyuan3D-2)（地区限制）：一张图生成静态 3D 模型，无骨骼，不能直接“穿”在形象上，适合鞋或配饰。
- [ChatGarment](https://github.com/biansy000/ChatGarment)（Apache-2.0）：图片 → 缝纫版型 → 3D 服装，研究代码，赛前用不上。
- 形象动画：MetaPerson 官方说明骨骼兼容 Mixamo（[文档](https://docs.metaperson.avatarsdk.com/mixamo)），three.js 有 `SkeletonUtils.retargetClip`；社区反映直接重定向可能出现脚、手朝向错误。最省事的做法是把 MetaPerson GLB 上传 Mixamo 直接下载带动作的文件（未验证）。

## 4. 对 D61 现场试穿的建议

| 方案 | 体验 | 工作量 | 成本 | 风险 |
| --- | --- | --- | --- | --- |
| **A. Decart 实时换装（推荐首选）** | 打开摄像头，实时看到“已经穿上这件”的视频；手机全屏、网站悬浮窗 | 约半天（参考官方 Next.js 示例；服务端签发临时令牌） | 0.02 美元/秒：演示 1 分钟约 1.2 美元 | 延迟、帧率、画质未实测；依赖网络；不支持鞋；手机需 HTTPS |
| B. 拍一下就试（兜底） | 摄像头取景 → 快门 → 10–20 秒后显示效果图 | 2–3 小时（复用现有 FASHN，或换 Kling Kolors 更快） | 0.07–0.075 美元/张 | 不是实时；需要加载态 |
| C. MediaPipe 贴图 + 拍照精修 | 实时跟随但像“贴纸”，侧身抬手会穿帮；拍照后用 B 出效果图 | 4–6 小时 | 同 B | 观感可能拉低整体质感 |

建议比赛版 **A 为主、B 兜底**：先用约 1–2 美元做一次 A 的实测（延迟、画质、衣服一致性），达标就上，不达标退回 B。试鞋放到赛后（Perfect Corp / Wanna 或自建 3D 鞋模）。

## 5. 对 D60 实时渲染的补充

- 赛前可验证：MetaPerson GLB + Mixamo 走路动画 + R3F 播放（约 1 小时验证骨骼与手机帧率）。能跑通即可做“本人形象实时走两步”，但身上不是这件商品。
- 赛后正路：商品 3D 服装化（目前没有成熟 API，要关注 Style3D 一类厂商开放，或自建版型 → 3D 流程）+ 形象实时动画。
- AI 视频（Kling、FASHN 视频）保留为按需生成，不作为常规功能（与需求变更 §7.3 一致）。

## 6. 需要发起用户决定

1. 是否采用 Decart 实时换装作为现场试穿主方案，并批准约 1–2 美元先做实测（从剩余 fal 预算出，剩约 9.6 / 20 美元）。
2. 现场测试的真人影像授权与 HTTPS（部署或隧道）授权（见需求变更 §7.2）。实时视频会把摄像头画面发给 fal / Decart 处理，需要在同意卡里单独列出这一第三方。
3. 2D 试穿是否从 FASHN 换成 Kling Kolors（更快、略便宜），或两者并存。
