## 方案与事实

新图为虚构成人、品牌、商品和数量。试穿人像的多角度、侧背与写实感不证明真实重建、模型精度或合身；个人私域和另购内容门票分开。旧图仅保留浅弧、玻璃、光影和手机版式基线，其搜索字段错配不能作为真实结果。

本轮未执行Agent、录音、上传、本人重建、真实试穿、付费或商品交易。用户已提出这些完整需求，实际首版、收费方式/阈值、路线与指标待定。
