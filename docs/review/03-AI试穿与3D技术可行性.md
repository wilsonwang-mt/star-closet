## 结论

44 小时内现实可达：一个 R3F 房间，1–3 件许可清楚、可真旋转的 GLB 服饰；语音或文字说需求，从受控目录挑出一套搭配；一个明确标注的 2D 生成试穿。用照片生成可旋转的本人 3D，这次做不到。

## 1. 前端与 3D

- 评审推荐 Vite + R3F 9.8.2 + drei 10.7.9 + three 0.186.1（2026-10-15 查 npm）：轮播、镜头飞入、聚光舞台在同一场景用代码控制。
- 不选 Spline：官方定价页写明代码导出与自托管只在 Enterprise 档，免费版带水印。model-viewer 4.4.0 只看单个模型，可作详情卡兜底。
- GLB 来源：
  - Khronos MaterialsVariantsShoe（CC-BY-4.0，Shopify），许可最干净。
  - Corset 为 CC0，但是“人台加束腰”，不算独立成衣。
  - Sunglasses / ChronographWatch 为 CC-BY，带商标条款。
  - Sketchfab 有 CC-BY 外套，需队员登录手动下载并逐件核许可，避开品牌款；迁移到 Fab 后能否下载待核实。
  - Smithsonian 3D 页面限非商用，不用。
  - Meshy/Tripo/Hunyuan3D 图生 3D 只作备份，按仓库规则必须标“参考重建”。
- 门槛冲突：文档写“17:00 仍无合格真模型即判失败”，但编码授权尚未给出；应改为相对授权时刻的门槛。

## 2. 试穿

- 主选 FASHN `tryon-v1.6`（`tryon-max` 为 Preview）：按需 $0.075/张，最少充值 $7.50（官方帮助中心）；base64 输入请求结束即删，CDN 输出 3 天过期，默认不用于训练；无删除接口，删除需邮件；延迟待实测。
- 备选 Vertex `virtual-try-on-001`：模型页标 GA、2026-01-20 发布、2027-01-20 停用；需开 GCP 计费；单价约 $0.06 仅见第三方，待核实。
- Kling Kolors 经 fal：fal 称含商用许可、$0.07/次，待核实。
- IDM-VTON / CatVTON：CC BY-NC-SA 禁商用且需自备 GPU，跳过。
- 照片转可旋转本人 3D：Ready Player Me 已于 2026-01-31 关停（厂商博客）；Avaturn/MetaPerson 价格待核实；SAM 3D Body 只恢复人体网格、无本人外观纹理。44 小时内不可行。
- 诚实标注三枚徽章：「2D 生成预览」「3D 可旋转：通用人台，非本人」「合身：未验证」；兜底用真实调用录下的「预录」片段；照片只用已同意的队员或合成人物，不进仓库。

## 3. 语音 → 搭配

- Web Speech API（Chrome/Edge/Safari，Firefox 未正式支持，zh-CN 待实测；Chrome 会把音频送到 Google）→ 可编辑识别文本 → 服务端 Claude 结构化输出 → `{top, bottom, shoes, accessory: item_id, reason}`。
- 目录为 20–30 件静态 JSON，整份放进 prompt；服务端拒绝目录外 ID 并重试或澄清；用户确认后才加入试衣间。
- 文字输入必须保留作兜底；不用向量库。

## 4. 文档问题与三大风险

- **会卡住 agent**：AGENTS.md、CLAUDE.md 仍写“不要开始写代码”、禁止装依赖。授权后第一个提交应是带日期的 AGENTS.md 授权补充（由发起人确认）。
- **过度设计**：39 个 ARC 中黑客松约需 8 个（F01/F08/F09/F10/F11/F27/F28/F30）；四账本、F35/F36 归因分账、F37 多租户、F38 删除链路、F39 GPU 成本观测、AIJob 幂等队列、PostgreSQL 均用不上。缺可执行的接口、目录结构和验收脚本。诚实标注规则值得保留。
- 风险一，没有合格 GLB：并行下载多个候选，图生 3D 作备份并标注。
- 风险二，镜头与手机 WebGL 性能吃掉周五：只做一个房间、烘焙光照、两档画质、周五上午真机测。
- 风险三，试穿 API 阻力（注册付款、延迟）：由队员本人开通并充值，授权后 4 小时内打通一次真实调用并录好预录兜底。
