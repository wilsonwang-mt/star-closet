# 评审报告 04 · 用户与商业模式

2026-10-15 15:50–16:00（UTC+8）。评审方式：AI 评审 agent 只读审阅基线 `4c8275c` 文档并检索行业资料，未改动文件。画像默认中文市场、以小红书为主要渠道——这是评审假设，仓库记录的市场仍未定。本文不是用户决定。

## 1. 痛点强弱

- **真且强：②网购靠想象、买错就退；④电商卖单品、人穿整套。** 两者是同一个痛：凑不齐整套只能靠想象，买错就退。尺码是服装退货首要原因（Akeneo 2025：58% 消费者这么说）；国内“女装退货率 60–80%”多来自媒体与商家口述，待核实。化身试穿回答“搭起来好不好看”，回答不了“合不合身”。
- **真，但无壁垒：①灵感落不了地；③按场景检索。** 场景检索已被大模型拉平，是基本功。
- **弱：⑤信任与隐私。** 卫生因素，不是购买理由。
- **伪或错位：⑥主理人变现难；⑦品牌故事讲不出。** 有粉丝的主理人变现已被 LTK、ShopMy、小红书买手解决；品牌缺的是可归因成交，不是讲故事工具。
- **首要画像**：已经关注团队那位顾问的 28 岁一线城市职场女性。下周去当婚礼宾客，收藏了几十篇笔记还凑不出一整套；上次网购三件退了两件。她是团队唯一能低成本触达的人。

## 2. 冷启动

- **供给就是顾问本人**：她是演示里唯一的主理人，衣橱类型用“风格主题”而非“明星”；用她自己或团队实拍的衣物与语音讲解；商品挂公开可购链接，只做导购不代收款——零授权风险。PRD §9 写了“先由时尚顾问策展”，入驻文档没有落地这一步。
- **明星入口现在是负资产**：民法典第 1019 条规定未经同意使用可识别肖像即构成侵权，营利不是前提；研究摘要提示“明星衣橱”有 2015 年同名应用，商标未核查——风险在产品名本身。建议演示用中性名，明星只作为“未来授权入口”一笔带过。

## 3. 商业模式：四类收入过早且互相冲突

- **门票 vs 隐私**：门票卖“私密”，文档又声明不卖隐私、防不住截图，卖点自我否定。
- **付费私密衣橱 vs 增长**：收藏阈值卡在最活跃用户身上，给留存最好的人设付费墙，还会诱发刷赞。
- **入驻费**：零供给时没人可收。
- **分成 vs 导购**：同一佣金池平台拿 40%，等于与小红书、LTK 抢主理人分成；LTK 商家平均佣金约 16%（第三方转引）。
- **早期只验证一个假设**：主理人策展＋试穿预览的“整套”，能否比单品带来更高整套加购率、更低退货意向。收入只保留导购佣金，早期几乎全给主理人。国内淘宝联盟、抖音精选联盟费率待核实。

## 4. 黑客松叙事

- 讲到：一个用户、一个场合、一位真主理人、一条收入线、一行单位经济，并明说早期不强求收入。
- 放进“未来”一页：门票、付费私密衣橱、入驻 A/B/C、四账本、RACI、广告叠加。

## 5. 文档问题

- `docs/商业模式与平台运营.md` §1：两个 P1 并列（B2B 建橱与商品），始终没选第一个下注方向。
- 同文件 §10：算例让平台承担 2% 支付费，隐含平台代收款，与零供给时唯一可行的外链导购不符。
- `docs/交易与履约方案.md` §2：外链导购被降为“替代”，“授权多商家平台”列为“重点评估”，与冷启动现实颠倒。
- `docs/入驻与Agent建橱.md`：全篇是 B2B 团队流程，没有写唯一的真实主理人怎么建第一个橱。
- 横向：“未定、不承诺、待核实”占比过高，读起来像团队不相信自己的产品；缺一页“我们相信什么、这周要证明什么”。
