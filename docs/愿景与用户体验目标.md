# 愿景与用户体验目标 · 建议稿

2026-10-15（Asia/Shanghai，UTC+8）。基于v0.3产品定位，对应用户本轮“愿景与用户体验目标是什么”的讨论。

状态：**团队讨论建议，尚未由用户确认定稿**。本文不增加已确认的技术承诺、收费规则或首版范围；当前需求仍以[PRD](PRD.md)和[决策记录](决策记录.md)为准。

## 1. 推荐愿景

**让每个人都能找到自己的风格，自信地表达自己。**

一句更接近体验的表达：**把喜欢的灵感，穿进自己的日常。**

愿景面向长期的用户变化：用户逐渐理解自己的偏好，能在自己的生活场景、预算与舒适需求内作出选择。明星、博主、品牌和主题提供灵感，个人风格可以来自多种来源；平台尊重用户自己的判断。

“每个人”意味着发现和表达的入口亲近、可理解；需要考虑不同身形、肤色、生活场景、预算和使用能力，不将某种身材、品牌或消费水平设为唯一标准。具体服务支持范围仍需按实际能力说明。

“自信”来自更充分的理解与自主选择，不能只用购买次数、消费金额或生成图片的好看来证明。

## 2. 产品使命与定位的关系

建议使命：**连接有审美的主理人、可信的服装配饰与AI搭配和试穿能力，让人更轻松地发现、尝试、整理和实现适合自己的穿搭。**

愿景描述长期改变，使命说明平台怎样创造价值；定位仍沿用v0.3的AI辅助策展衣橱、个人试衣间与选购平台。空间、AI、个人形象和交易共同服务用户任务，单独具备其中一项不能说明体验成立。

## 3. 五个消费者体验目标

| 目标 | 希望用户产生的感受 | 产品需要兑现 | 可观察的证据候选 |
| --- | --- | --- | --- |
| 发现共鸣 | “这里有我喜欢、也想尝试的风格。” | 主理人/品牌/主题清楚，空间有质感、单品可理解；场景和预算也能直接检索 | 用户能说出喜欢的风格与原因，找到相关内容，发现一个有意义的新搭配 |
| 表达被理解 | “我说清自己的生活需求，它能理解并帮我想。” | 文字或语音承接场合、预算、舒适度与偏好；识别可纠正、理由可解释、推荐可修改 | 用户确认约束正确，纠错后得到更相关的方案，预算不被默默扩大 |
| 尝试更具体 | “我能更清楚地想象，这套搭配穿在自己身上是什么感觉。” | 核心商品真实旋转，支持的本人试穿模式标明能力；组合可替换和对比 | 用户辨认差异并解释取舍；能分辨视觉预览、尺寸资料与尚不能判断的部分 |
| 选择更安心 | “我知道为什么选，也知道购买和数据处理会发生什么。” | 商品关系、卖方、费用、配送、售后与付费权益清楚；不默认付款，身体资料处理由本人掌控 | 用户能说明重要条件、限制与责任，主动选择保存、调整、购买或合理排除 |
| 风格能积累 | “上次喜欢的东西和搭配还在，我可以继续完善。” | 试衣间、收藏与私密衣橱分工清楚，回来能接续，能复用保存的搭配；本人空间仅本人可见 | 用户再次回来继续任务，找到旧选择并复用；清楚容量、收费和导出删除方式 |

空间体验建议呈现出“有审美、值得探索的线上买手店”：浅弧陈列吸引浏览，光影与聚光帮助理解服饰，玻璃界面保持信息可读。手机上的寻找、修改与返回同样轻松；视觉氛围应和日常任务一起验收。

个人三维形象、真实服饰模型和试穿分别验证。“更具体地想象”不等于已经能准确测量或保证合身；当前尚无对应效果与时延实测。完整目标见[AI试穿与个人形象](AI试穿与个人形象.md)。

## 4. 主理人的体验目标

**“我能更轻松地把自己的审美表达出来，掌握发布内容，并看清投入与回报。”**

- 用照片、视频、语音启动工作，不要求先学会专业场景制作；实际模型与资料要求仍要明确。
- Agent帮助整理与提出草稿，主理人可以纠正事实、选择陈列、确认版本；团队协作有明确分工。
- 经营报告能够解释内容带来的有效反馈、净成交与收益，同时看得见制作、维护和服务成本。
- 可持续收益是经营目标，不能保证每位主理人必然赚钱。平台推荐应服务消费者任务，商业推广和分成关系透明。

可观察证据包括草稿到可发布的时间、人工修订负担、内容维护意愿、账目理解与实际净收益。当前没有上述实测数据。

## 5. 一次理想体验

用户说：“下周见客户，想穿得精神一点，走路舒服，预算有限。”

平台先让用户确认理解到的场合、预算和偏好，带出相关主理人或主题中的服装与鞋包组合。用户把候选放入个人试衣间，替换一件不喜欢的外套，在需要时选择本人形象预览；系统说明当前能展示的效果和仍需查阅的尺码信息。

用户保存一套满意搭配，或进一步确认规格和购买条件；也可以了解后决定暂时不买。下次回来，原来的选择和修改仍可接续。一次成功体验的结果，是用户更清楚自己要什么，并且能够作出有依据的决定。

这是建议的目标场景，不是应用现有能力或首版验收通过记录。

## 6. 团队设计取舍

1. 尊重个人：推荐服务实际场合、预算和舒适需求，不用单一审美或身体标准替用户下结论。
2. 支持探索：免费发现有价值，能够轻松修改、撤销和退出；付费内容、空间与生成服务说明清楚。
3. 建立可信的真实感：服饰、个人形象与能力标签对应，不用画面逼真替代来源、尺寸或合身证据。
4. 保持自主：推荐不自动付款，粉丝支持不隐藏内容交付责任，消费者私域不开放给创作者团队。
5. 形成连续体验：回来能接续有意义的选择；持续价值来自搭配和理解，而非人为锁住资料。

这些是建议原则，需经团队讨论和用户研究确认；不改变既有“个人衣橱仅本人”的明确约束。

## 7. 如何衡量体验目标

建议北极星候选：**每周完成有效穿搭任务的用户数**，配套观察次周复访及任务后的满意度。

“有效”需有明确场景/约束、相关方案与用户可解释的选择；保存、调整、购买和合理排除均可产生价值，但不能把任意点击或离开页面都计为成功。建议通过可用性观察和采样回访校验事件口径，再确定量化门槛。

| 维度 | 建议观察 | 防止误判 |
| --- | --- | --- |
| 启发 | 找到相关风格及新的搭配可能 | 停留长不一定有收获 |
| 理解 | 约束正确、纠错成本、推荐采纳理由 | 语音转写成功不等于被理解 |
| 决策 | 对比后取舍、条件理解与预期校准 | 更有自信不等于信息更准确 |
| 连续性 | 返回继续、搭配复用与满意度 | 收藏数量本身不代表长期价值 |
| 主理人 | 时间成本、维护意愿、实际净收益 | 发布数量和待确认佣金不等于成功 |
| 信任 | 越权、误导、退款/撤权和删除处理 | 成交增长不能掩盖体验损害 |

当前阶段先确认体验假设和观察方法；具体目标值、样本、支持人群与设备待定，不能宣称已达标。
