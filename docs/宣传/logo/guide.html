SEEN. 标识使用规范

安全边距与组合

以字标中 E 的宽度 为单位 x，标识四周至少留出 1x 空白。竖排用于封面、海报、片尾；横排用于网站顶栏和 PPT 页眉页脚。

两个光学尺寸

  • display　字高 ≥ 48px：宣传片、海报、PPT 封面、发布会大屏。保留高反差与句点光晕。
  • text　字高 16–48px：网站顶栏、PPT 页脚、文档。横笔加粗、字距放宽、句点不发光。
  • 图形小尺寸版　≤ 64px：网站小图标、头像角标，笔画加粗、无光晕。
  • 最小尺寸　字标字高 16px，图形宽 24px；更小时只用图形。

颜色

默认用深底。浅底版本只用于浅色 PPT 与文档，不加光晕。灯泡与问号挂钩永远是香槟色，其余部分为单一墨色。

宣传片与动效

  • 使用 seen-motion-hero.svg，部件已分组命名：hook、bulb、shoulders、bar、glow、beam、S、E1、E2、N、period。
  • 揭幕顺序：问号挂钩出现 → 点亮灯泡（bulb）→ 光晕铺开（glow）→ 衣架线条描出（shoulders、bar）→ 光束落地（beam）→ 字母依次浮现 → 句点最后亮起。
  • 辅助图形 ≡ 用于加载动画（三道横杆依次亮起）与周边印花，不与主标识并排使用。
